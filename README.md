# Assembly-Adventure
Using assembly MIPS, this project is a terminal videogame in which you can:
1. Insert a player.
2. Insert a team.
3. Assign players to a team.
4. Print all players.
5. Print all teams.
6. Search player by ID.
7. Search team by name.
8. Simulate a duel between two players.
9. Simulate a team match between two teams.
10. Register match results.
11. Print match history.
12. Print ranking of players by score.
13. Print ranking of teams by wins.
14. Print the strongest player by derived power score.
15. Print the strongest team.
16. Print all matches won by one team.
17. Print players not assigned to any team.
18. Logical deletion of player or team.
19. Recursive feature: recursive simulation log printer or recursive search through
team roster.

Each player record must contain at least:
• player ID
• nickname
• level
• attack points
• defense points
• energy
• wins
• losses
• active flag

Each team record must contain at least:
• team ID
• team name
• up to 5 player IDs
• total wins
• total losses
• active flag

Each match record must contain at least:
• match ID
• team A ID
• team B ID
• winner team ID
• number of rounds
• active flag
